## What is Performly?

A personal performance tracker built in Python. Track your daily habits, goals, and metrics in one place. See where your time is going and what's actually moving the needle.

---

## Features (In Progress)

- Daily habit tracking with streaks
- Custom metric logging (sleep, exercise, focus hours)
- Weekly performance reports
- Terminal-first interface

---

## Quick Start

`bash
git clone https://github.com/PhaNtoM-GHosT-11101/performly
cd performly
pip install -r requirements.txt
python main.py
`
